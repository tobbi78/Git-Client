Versionshistorie Neue Funktionen und Fehlerbehebungen je Version

Version 1.1

Neu: Lazy Loading der Commit-Liste

Große Repositories werden jetzt deutlich schneller geöffnet. Beim Start lädt die App nur die neuesten 2.000 Commits (Standardwert). Sobald du ans Ende der Liste scrollst, werden automatisch weitere Commits nachgeladen — ohne manuellen Eingriff, so lange bis die vollständige Historie angezeigt wird.

Neu: Einstellungen (⌘,)

Im neuen Einstellungsdialog lässt sich die Anzahl der Commits pro Ladevorgang anpassen. Änderungen werden erst mit Speichern übernommen; mit Abbrechen (Esc) werden sie verworfen. Wird das Fenster über den roten Schließen-Button geschlossen und es gibt ungespeicherte Änderungen, erscheint eine Warnung.

Neu: Repository klonen

Repositories können jetzt direkt aus der App heraus über eine HTTPS-URL geklont werden. Für private Repositories lassen sich Benutzername und Passwort/Token angeben. Die Zugangsdaten werden sicher im macOS Keychain gespeichert — nie in einer Datei.

Fehlerbehebungen

  • Commit-Graph ohne Lücken zwischen den Zeilen.
  • Diff-Panel füllt jetzt die volle Breite rechts der Seitenleiste aus.
  • Beim Öffnen eines Repositories wird eine sinnvolle Fenster-Mindestbreite gesetzt.
  • Platzhalter-Ansichten (leere Zustände) füllen die volle Breite aus.

Sonstiges

  • Unit-Test-Abdeckung auf 83 % der nicht-View-Dateien erhöht.
  • Hilfe um Speicherpfade, Lazy Loading, Einstellungen und Sicherheitskonzept erweitert.

Version 1.0

Erste Veröffentlichung. Enthält:

  • Bookmark-Browser mit Ordnern, Drag & Drop und Kontextmenü.
  • Commit-Graph mit farbigen Lanes, Ref-Badges (Branch, Tag, HEAD).
  • Diff-Ansicht im einheitlichen Patch-Format.
  • Branch- und Tag-Navigation mit Sprung zum zugehörigen Commit.
  • Neu-laden-Funktion (↺) für externe Git-Operationen.
