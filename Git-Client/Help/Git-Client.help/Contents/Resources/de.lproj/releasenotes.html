Version 1.2

Neu: Commit-Suche & Filter

Die Commit-Liste lässt sich jetzt durchsuchen und filtern — nach Nachricht, Autor oder Zeitraum (Von/Bis mit Uhrzeit). Die Eingabe wird entprellt, sodass die Suche auch in großen Repositories flüssig bleibt.

Neu: Erweiterte Dateiliste pro Commit

Zu jedem Commit zeigt die Dateiliste nun den Änderungstyp (hinzugefügt, geändert, gelöscht) als Symbol sowie die +/−-Zeilenstatistik. Ein Klick auf eine Datei springt direkt zum Diff.

Neu: Ahead/Behind-Anzeige pro Branch

In der Seitenleiste zeigen Badges an, wie viele Commits ein Branch vor bzw. hinter seinem Remote liegt.

Neu: JIRA-Verknüpfung

Ticket-Keys wie PROJ-123 in Commit-Nachrichten werden erkannt und als klickbare Links dargestellt. Server-URL und Projekt-Keys werden unter Einstellungen › JIRA konfiguriert.

Neu: Blame-Ansicht

Per Rechtsklick auf eine Datei im Commit-Detail lässt sich anzeigen, wer welche Zeile zuletzt geändert hat — inklusive Commit und Autor je Zeile.

Neu: Automatische Erkennung neuer Commits

Git-Client beobachtet Repositories im Hintergrund (FSEvents lokal) und fragt den Server periodisch per git ls-remote ab — ohne Download. Neue Commits erscheinen als Badge in der Übersicht und als Hinweis-Banner im geöffneten Repository. Intervall und Aktivierung unter Einstellungen › Aktualisierung.

Neu: Zeilennummern im Diff

Der Diff-Patch kann links neben jeder Zeile die alte und neue Zeilennummer anzeigen — wie in Sourcetree oder GitHub. Umschaltbar unter Einstellungen › Anzeige.

Neu: Erscheinungsbild wählbar

Das Design lässt sich auf Hell, Dunkel oder Wie System einstellen (Einstellungen › Anzeige). Die Änderung greift sofort ohne Neustart.

Fehlerbehebungen

  • Absturz (EXC_BAD_ACCESS) im Hintergrund-Watcher behoben: der FSEvent-Callback hat den CFArray-Pointer falsch interpretiert und dabei in ungültigen Speicher gelesen.

Sonstiges

  • Über-Dialog um Copyright und Credits erweitert.
  • Git-Client bleibt ein reiner Lese-Client: keinerlei schreibende Git-Operationen.

Version 1.1

Neu: Lazy Loading der Commit-Liste

Große Repositories werden jetzt deutlich schneller geöffnet. Beim Start lädt die App nur die neuesten 2.000 Commits (Standardwert). Sobald du ans Ende der Liste scrollst, werden automatisch weitere Commits nachgeladen — ohne manuellen Eingriff, so lange bis die vollständige Historie angezeigt wird.

Neu: Einstellungen (⌘,)

Im neuen Einstellungsdialog lässt sich die Anzahl der Commits pro Ladevorgang anpassen. Änderungen werden erst mit Speichern übernommen; mit Abbrechen (Esc) werden sie verworfen. Wird das Fenster über den roten Schließen-Button geschlossen und es gibt ungespeicherte Änderungen, erscheint eine Warnung.

Neu: Repository klonen

Repositories können jetzt direkt aus der App heraus über eine HTTPS-URL geklont werden. Für private Repositories lassen sich Benutzername und Passwort/Token angeben. Die Zugangsdaten werden sicher im macOS Keychain gespeichert — nie in einer Datei.

Fehlerbehebungen

  • Commit-Graph ohne Lücken zwischen den Zeilen.
  • Diff-Panel füllt jetzt die volle Breite rechts der Seitenleiste aus.
  • Beim Öffnen eines Repositories wird eine sinnvolle Fenster-Mindestbreite gesetzt.
  • Platzhalter-Ansichten (leere Zustände) füllen die volle Breite aus.

Sonstiges

  • Unit-Test-Abdeckung auf 83 % der nicht-View-Dateien erhöht.
  • Hilfe um Speicherpfade, Lazy Loading, Einstellungen und Sicherheitskonzept erweitert.

Version 1.0

Erste Veröffentlichung. Enthält:

  • Bookmark-Browser mit Ordnern, Drag & Drop und Kontextmenü.
  • Commit-Graph mit farbigen Lanes, Ref-Badges (Branch, Tag, HEAD).
  • Diff-Ansicht im einheitlichen Patch-Format.
  • Branch- und Tag-Navigation mit Sprung zum zugehörigen Commit.
  • Neu-laden-Funktion (↺) für externe Git-Operationen.
